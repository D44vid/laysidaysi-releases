# Laysidaysi releases

Downloads and the website for [Laysidaysi](https://laysidaysi.com), a calm Mac app for
timeboxing with distraction protection.

- **Download:** [latest release](https://github.com/D44vid/laysidaysi-releases/releases/latest)
- **Website:** https://laysidaysi.com (branch `gh-pages`)

Everything here is published automatically by the release workflow. Installed apps check
`https://laysidaysi.com/updates/stable/latest.json` for updates and only install files signed
with the Laysidaysi update key.

Questions: hello@laysidaysi.com
